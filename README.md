# Digital Hunters - XR Game Studio UI 🎮🌌

A sleek, futuristic front-end web interface for a fictional mobile and XR game development studio. This project focuses on translating a high-fidelity, sci-fi static design into a fully functional, pixel-perfect HTML/CSS layout.

## 🚀 Overview

This project was built to practice and showcase modern CSS layout techniques, specifically focusing on complex Flexbox structures, glassmorphism UI trends, and visually engaging neon accents over dark themes.

## ✨ Features

* **Modern Dark Theme:** Utilizes a deep space aesthetic with vibrant `#07d0ba` neon cyan accents to fit the gaming niche.
* **Glassmorphism Effects:** Interactive UI cards featuring smooth background blurs (`backdrop-filter`) and semi-transparent borders for a premium, layered depth.
* **CSS Flexbox Architecture:** Clean and organized layout alignment across all sections without relying on heavy external frameworks.
* **Custom Typography:** Integrated Google Fonts (*Orbitron* for technical headers and *Montserrat* for readable body copy) to elevate the futuristic aesthetic.
* **Semantic HTML:** Clean, readable, and well-structured markup.

## 🛠️ Technologies Used

* **HTML5**
* **CSS3** (Flexbox, Pseudo-elements, Viewport Units)
* **Icons:** RemixIcon

## 💡 Key Learnings

During this build, I strengthened my understanding of:
* Implementing **Glassmorphism** effectively using `backdrop-filter` to create frosted glass effects overlaying complex background images.
* Managing overlapping visual elements and absolute positioning to create depth (like the central hero character and floating stat stars).
* Creating cohesive, glowing hover states using `box-shadow` and smooth `transition` properties.
